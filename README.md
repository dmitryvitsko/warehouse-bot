# 📦 Warehouse Bot — Автоматизация складского учета и подотчета мастеров

**Warehouse Bot** — это специализированный Telegram-бот на **Java**, разработанный для автоматизации учета кабельно-проводниковой продукции и расходных материалов в подразделениях технической эксплуатации и бюро ремонта телекоммуникационных сетей.

Проект решает главную проблему материально ответственного лица (МОЛ): переводит учет выдачи материалов мастерам, расчет стоимости с НДС для квитанций и формирование ежемесячной бухгалтерской отчетности из бумажных блокнотов и разрозненных таблиц в единую базу данных с доступом со смартфона.

---

## 🎯 Основные задачи, которые решает бот

1. **Прозрачный баланс «Склад ↔ Мастер»:** точный учет того, сколько материалов находится на основном складе МОЛ, а сколько — в сумках и автомобилях каждого конкретного инженера/монтера.
2. **Автоматический пересчет единиц измерения:** перевод неудобных бухгалтерских единиц из оборотных ведомостей (`км`, `тыс. шт`, `уп`) в понятные рабочие единицы (`метры`, `штуки`) при выдаче и обратная конвертация при формировании итогового отчета.
3. **Автоматический расчет НДС (+20%):** в бухгалтерской ведомости цены идут без НДС, а в квитанцию абоненту мастер обязан вписать стоимость с НДС. Бот считает это автоматически и выдает готовую сумму к оплате.
4. **Раздельный учет списаний (Платные / Технические):** разделение расхода материалов на платные работы (по вине абонента с привязкой к номеру квитанции) и эксплуатационные работы (износ линии, повреждение грызунами и т.д.).
5. **Интерактивная шпаргалка тарифов:** встроенный справочник стоимости услуг (вызов специалиста, оконцевание кабеля UTP, монтаж розеток и др.) для быстрого заполнения нарядов и квитанций у абонента.

## ⚙️ Функциональные возможности по ролям

Доступ в системе разделен по уникальному `Telegram ID` пользователя на две роли:

### 👷 Роль «Мастер бюро ремонта» (`WORKER`)
* **📦 Просмотр витрины склада:** актуальные остатки доступных материалов на складе МОЛ с отображением цены за единицу с учетом НДС (+20%).
* **➕ Взятие материалов в подотчет:** выбор позиции через Inline-кнопки и мгновенное зачисление нужного метража/количества на личный баланс сотрудника.
* **🧰 Контроль личного подотчета:** просмотр списка всех материалов, числящихся за мастером в текущий момент.
* **📝 Пошаговое списание материалов (FSM-диалог):**
    * **По квитанции (вина абонента):** последовательный ввод *Номера квитанции → Телефона заявки → Номера договора → Адреса* с автоматическим расчетом итоговой суммы материала с НДС для вписывания в бланк.
    * **Без квитанции (технический расход):** ввод *Телефона заявки → Номера договора → Адреса* и выбор причины списания (*Повреждение грызунами*, *Обрыв / износ линии*, *Плановая замена*).
* **📋 Тарифы услуг:** быстрый просмотр прейскуранта на работы по категориям.

### 👨‍💼 Роль «Администратор / МОЛ» (`ADMIN`)
Включает все возможности мастера, а также панель управления складом:
* **📊 Мониторинг «У кого что на руках»:** сводный отчет в реальном времени по всем подчиненным и числящимся за ними материалам.
* **📥 Импорт оборотной ведомости (Excel `.xlsx`):** загрузка бухгалтерской ведомости прямо в чат бота для актуализации номенклатуры, цен и остатков склада с учетом материалов, уже находящихся на руках у людей.
* **📑 Генерация месячного отчета в 1 клик:** автоматическая сборка и выгрузка в чат многостраничного файла `Otchet_Sklad.xlsx` (4 листа).
* **➕ Управление справочником тарифов:** добавление новых видов работ и цен прямо через команды в чате.

## 📊 Структура генерируемого Excel-отчета (`Otchet_Sklad.xlsx`)

По запросу МОЛ бот формирует готовый файл `.xlsx` с помощью библиотеки **Apache POI**, разделенный на 4 тематические вкладки:

| Вкладка | Содержание | Назначение |
|---|---|---|
| **1. По квитанциям (Платные)** | Дата, ФИО мастера, Код, Материал, Кол-во, Сумма с НДС, № Квитанции, Телефон заявки, № Договора, Адрес | Сверка платных нарядов и квитанций |
| **2. Без квитанций (Тех. расход)** | Дата, ФИО мастера, Код, Материал, Кол-во, Телефон заявки, № Договора, Адрес, Причина списания | Формирование актов на списание по эксплуатации |
| **3. Сводная для бухгалтерии** | Суммарный расход по каждому номенклатурному коду в рабочих (`м`, `шт`) и бухгалтерских (`км`, `тыс. шт`) единицах | Прямой перенос итоговых цифр в бухгалтерский отчет |
| **4. Остатки (Склад и Мастера)** | Детализация текущих остатков: сколько лежит на складе МОЛ и сколько числится за каждым сотрудником | Инвентаризация и контроль на конец месяца |

## 🛠 Технологический стек и инструменты

* **Язык программирования:** Java (JDK 17+ / 26)
* **Система сборки:** Apache Maven
* **Telegram API:** `TelegramBots` (Long Polling Bot, Reply & Inline Keyboards, State Machine)
* **База данных:** `SQLite` (`sqlite-jdbc`) — встроенная реляционная СУБД с поддержкой ACID-транзакций (исключает коллизии при одновременном взятии материалов со склада)
* **Работа с документами Excel:** `Apache POI` (`poi-ooxml`) — чтение и генерация таблиц формата `.xlsx`
* **Логирование:** `SLF4J` (`slf4j-simple`)

## 🗄 Архитектура проекта и базы данных

Проект имеет модульную структуру (`src/main/java`):
* `Main.java` — точка входа, инициализация БД и регистрация сессии бота.
* `WarehouseBot.java` — контроллер Telegram-бота, маршрутизация команд, управление клавиатурами и состояниями пошагового диалога.
* `DatabaseManager.java` — слой работы с БД (DAO): создание схемы, управление транзакциями выдачи/списания, пересчет НДС и единиц измерения.
* `WriteOffSession.java` — модель состояния (State) для пошагового мастер-диалога списания материалов.
* `ExcelReportGenerator.java` — сервис генерации многостраничных Excel-отчетов.

**Схема базы данных (`warehouse.db`) включает 5 таблиц:**
1. `users` — сотрудники и их роли (`ADMIN` / `WORKER`).
2. `materials` — номенклатура склада, коэффициенты конвертации единиц (`conversion_factor`), цены без НДС и с НДС.
3. `employee_balances` — текущие остатки материалов на руках у каждого сотрудника.
4. `transactions` — полный журнал операций (`IMPORT`, `ISSUE`, `WRITE_OFF`, `RETURN`) с реквизитами абонентов и квитанций.
5. `service_tariffs` — справочник стоимости работ и услуг.

## 🚀 Быстрый запуск и настройка

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/ВАШ_ЛОГИН/warehouse-bot.git](https://github.com/ВАШ_ЛОГИН/warehouse-bot.git)
   cd warehouse-bot
   ```

2. **Создайте файл конфигурации `config.properties` в корне проекта:**
   *(Файл добавлен в `.gitignore` в целях безопасности и не публикуется в репозитории)*
   ```properties
   bot.token=ВАШ_ТОКЕН_ОТ_BOTFATHER
   bot.username=ИМЯ_ВАШЕГО_БОТА
   ```

3. **Укажите свой Telegram ID администратора:**
   В классе `DatabaseManager.java` укажите ваш `ADMIN_ID`, чтобы бот автоматически предоставил вам права МОЛ.

4. **Соберите и запустите проект:**
   Запустите класс `Main.java` из IntelliJ IDEA или через консоль Maven:
   ```bash
   mvn compile exec:java -Dexec.mainClass="Main"
   ```
   При первом запуске база данных `warehouse.db` и все необходимые таблицы создадутся автоматически.
